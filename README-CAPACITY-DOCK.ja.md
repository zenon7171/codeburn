# Capacity Dock 日本語版

ClaudeとCodexの使用率を、画面の端のアイコンと詳細カードで確認するmacOSアプリです。READMEの「Capacity Dock」の画像にある機能だけを使いたい方向けの、非公式のオープンソース版です。

**Electron Desktop、費用ダッシュボード、セッション集計、CodeBurn CLIは起動しません。** 接続と表示の設定だけを備えています。元のCodeBurnと同じMITライセンスで、ソースはこのリポジトリの `mac/` にあります。

## ビルドして起動する

このビルドスクリプトはApple Silicon専用です。ビルドにはmacOS、XcodeとSwiftが必要です。検証環境はSwift 6.3.3。生成アプリの対象はmacOS 14以降です。Node.jsやnpmは不要です。

リポジトリのルートで実行します。

```sh
bash mac/Scripts/package-capacity-dock-ja.sh
```

末尾に表示される `mac/release-capacity/0.9.23-XXXXXX/` に、次の成果物ができます。毎回別のフォルダーを作るため、以前のアプリを上書きしません。

- `image/Capacity Dock.app`：起動するアプリ
- `CapacityDock-JA-0.9.23-arm64.dmg`：配布用ディスクイメージ
- `CapacityDock-JA-0.9.23-arm64.zip`：ZIP版
- `SHA256SUMS`：チェックサム

生成物はGit管理外です。GitHubからソースを取得した場合は再ビルドしてください。アプリはアドホック署名で、Appleの公証は受けていません。OSの警告は内容を確認してください。ビルドスクリプトはアプリのインストール・起動、セキュリティ設定の変更を行いません。

`CodeBurn.app` や `codeburn menubar` とは別の起動経路です。Dock専用版を使う場合は **`Capacity Dock.app`** を開いてください。

## 実アカウントを接続する

1. 利用するアカウントでClaude Code／Codexにログインしておきます。
2. `Capacity Dock.app` を開きます。初回は「接続・表示設定」が表示されます。
3. Claude／Codexの必要な方の「接続」を押します。Claudeはキーチェーンの確認が出る場合があります。
4. 画面右端のアイコンにカーソルを合わせると、期間ごとの使用率とリセットまでの時間が表示されます。

未接続のアイコンは `--` です。通常起動で仮データは表示しません。接続後は約60秒ごとに更新し、取得制限が返された場合は待ってから再試行します。メニューバーから「今すぐ更新」も選べます。

**パーセントは「使用済み」の割合です。** 公式画面の「残り90%」に対応する表示は「使用率10%」です。リセット時刻はAPIの値を使い、カードには相対時間を表示します。同じアカウント・期間で比較してください。通信失敗時に前回の値を残す場合は、その旨を表示します。

## 表示と終了

- 初期設定ではClaudeとCodexの2つのアイコンを常に表示します。カーソルを離しても、外側をクリックしても1つには戻りません。詳細カードはカーソルを合わせたときに表示します。
- 「接続・表示設定」の「選択したアイコンを常に表示」をオフにすると、通常時は優先アイコン1つになり、カーソルを合わせると展開する動作に戻せます。設定は再起動後も保持します。
- ドラッグで位置を変更できます。右クリックの「画面の端に配置」で左右・上下を選択できます。
- メニューバーの「接続・表示設定」で、表示するプロバイダー、通常表示するアイコン、サイズを変更できます。
- 「監視を停止」は、このアプリからの取得を止めます。Claude Code／Codexからのログアウトや、他のアプリ・テストの停止は行いません。
- アプリの終了はメニューバーの「Capacity Dockを終了」です。ログイン時の自動起動は登録しません。

## 認証と通信

初回は「接続」を押すまで認証情報を読み取りません。接続したプロバイダーについては、次回起動後も使用率を更新します。使用率の取得はClaude／OpenAIのサービスへの通信を伴います。認証情報やレスポンスを画面のエラー文に出しません。

アプリID、設定、専用キーチェーンのサービス名、旧キャッシュの保存先は元のCodeBurnから分離しています。Codexのログインファイルは既存実装と同じく共有し、期限切れトークンの更新時には更新結果をログインファイルへ戻します。別のアカウントで使う場合は、Claude Code／Codex側で切り替えてから再接続してください。

CodeBurnのCLIデーモン、ログ走査、費用レポート、テレメトリ、更新確認、他のプロセスの終了処理は、この起動経路では実行しません。認証・使用率の取得にはupstreamの実装を再利用しており、提供元の仕様変更で再接続や修正が必要になる場合があります。

## 開発者向け

`CAPACITY_DOCK_ONLY` コンパイルフラグで、最小の起動処理と日本語UIを選択します。通常のCodeBurnの起動経路もソースに残してあります。

```sh
swift test --package-path mac --scratch-path mac/.build-capacity-tests --jobs 4 --filter 'DockOnlyTests|CapacityDock'
```

配置・表示、初回の未接続、明示的な接続、監視停止後の応答破棄、通信失敗、APIの週間使用率とリセット日時、日本語表示を検証します。認証情報や実APIを使わずに確認します。

開発用の `--demo` 起動は通信しない仮データ表示です。プラン欄に「サンプル」と表示され、実アカウントの使用率・リセット時刻とは一致しません。普段は指定しないでください。
